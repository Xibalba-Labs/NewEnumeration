# NewEnumeration
NewEnumeration is a lightweight, zero-dependency, high-performance Smart Enum implementation for .NET. Designed as a modern, maintained replacement for legacy enumeration packages, it brings full support for .NET Standard 2.0 through .NET 9+, Native AOT compatibility, System.Text.Json serialization, and EF Core.

The zero-effort, drop-in replacement for the legacy enumeration package on modern .NET (.NET Standard 2.0 to .NET 9+). Same API, modern performance, active support.
